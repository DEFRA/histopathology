General Information

The page header

A common page header section is displayed at the top of each page in the system.

The centre section of the page header displays the name of the system ("Histopathology Submissions"), the version of the system, the name of the page you are currently viewing, and a "breadcrumb trail" showing you which section of the system you are in.

The right hand block of the page header displays the name of the currently logged-on user, the user group and area that the user is assigned to. It also displaysthe current submission number if you are editing or processing a submission. Below this are two links that allow you to return to the home screen or access the help pages from anywhere in the system.

 

Date entry controls

To enter a date in a date entry control, click the calendar button to the right of the text box:

A calendar will be displayed allowing the selection of a date. To close the calendar again without selecting a date, click the calendar button a second time.

Alternatively, a date may be directly typed in the box (in the format dd/mm/yyyy).

 

Data grids

To select a row in a data grid, click the arrow button at the left-hand end of the row: . The selected row will be highlighted in a different colour.

The buttons at the bottom of the grid may be used to perform row operations:

   Add a new row

   Edit the currently selected row

   Remove the currently selected row from the grid

After pressing the New or Edit button, the grid will be placed in to edit mode, and you can change the values in the cells. After making changes, use the following buttons to confirm or cancel those changes:

   Save changes

   Cancel changes - the data in the row will revert to the values that were present before entering edit mode.

If the New, Edit or Delete buttons appear in grey; this indicates that the particular function is unavailable at this time.

If a grid contains more than one page of data, then the navigation buttons at the bottom left of the grid may be used to change between pages:

   Move to the first page

   Move to the previous page

   Move to the next page

   Move to the final page

The page number links, next to the navigation buttons, can be used to move directly to a given numbered page. At the bottom right of the grid the currently displayed page number is shown, along with a count of the total number of pages available.

Some grids will allow sorting by means of clicking on the column headers. If this is the case, then the column headers will appear underlined. The first click on the column header will cause the grid rows to be sorted by that column in ascending order; a second click on the same column will sort in descending order.

 

Pick Lists

You will find that all pick lists have an empty entry as the first entry. This is so that it is readily distinguishable which field shave had data entered and which have not. It also allows you to blank out the field from a previous selection. For example, if you have filled in some search criteria on the View Submissions page and now wish to remove one, rather than having to clear the whole criteria using Clear Search, you can just change the particular field entry to the blank entry in the pick list, and press Search.

 

Field error messages

If required data is missing, or invalid data has been entered when a form is saved, the error may be indicated by a red star next to the relevant field. Placing the mouse cursor over the star will cause a tool tip message to pop up, indicating the reason for the error: for example, it may indicate that the field is mandatory, or in the case of an invalid entry, it may indicate the required format.

 

Export to Excel

Data displayed in several of the grids can be saved and viewed as an Excel spreadsheet. When you click on this link, an empty ExcelExport browser window will open and a File Download box displayed, asking if you want to Open or Save the file. Selecting Open will load the file into Excel from where it can be saved to your local disk. Selecting Save will display the Save As dialog box prompting you to enter the file name. You may need to close the Download box when the file has been saved. You can then close the ExcelExport browser window as it is no longer required.

 

Saving Data

Data is only saved to the system when you press the Finish or Done button on the screen. Until then, the data is being stored and manipulated on the screen only. For example, on the Quality Data page, you may press Update Selected as many times as you need to apply data to the test, however, the changes are only saved to the database system when you press Done.

  

Application Error

This screen is displayed if the system has encountered an unexpected problem. Details of the error are shown, which a system administrator may be able to use to determine the cause of the problem.

The information displayed will also have been recorded in the system log, which the system administrator can view. To help the administrator determine the cause of the problem, you can record additional information about what you were doing when the error occurred in the text box at the bottom of the screen. Click the Save button and the information you entered will also be saved to the system log, for later analysis by the system administrator.

After an error has occurred, it is advisable to use the Home link in the page header to return to the Home screen. If the error has occurred before the data you were working on was saved, that data will have been lost.

Submission Details

This screen asks for general information concerning the submission.

The Entered By field will be pre-filled and cannot be edited. It shows which user entered the submission onto the system. Entered Area shows which Area this user belongs to.

The Submitted By field is set to the logged on user's name by default. Select the name of the submitter from the drop-down list if you are entering the submission on someone's behalf. If the name of the submitter does not appear in the drop-down list, click on the New button, which will allow you to add their name to the list, from the standard grid controls. The Submitted Area field will be set to the area to which you belong. You will not normally be able to change this field.

Select the Project or Contract code for which you are submitting the samples from the drop-down list. Only one project code may be selected per submission. If the code does not appear on the list, use the New button to add a new project code from the standard grid controls. The Submission Date defaults with today's date. If you wish to enter the submission on the system in advance of submitting the material, you can change the date using the Date Entry control.

Select the Pathologist from the drop-down list. If the pathologist does not appear on the list, use the New button to add a new pathologist from the standard grid controls. This field is mandatory.

Select the required fixation from the drop-down list.

Select the Species of the samples being submitted from the drop-down list. Only one species may be selected per submission. If the species required is not on the list, you will need to contact Histopathology. This field is mandatory.

In the Is it adequately fixed? field, select Yes or No as appropriate. This field is mandatory.

Some users will have an additional Same project code for all samples? checkbox displayed, where the system is integrating with another database. By default this option is checked, which means you will not be able to add samples to the submission that have different project code. Turning off this option will allow you to mix samples from different project codes on the same submission.

Submitted As displays the option you selected on the previous Submission Type page. This cannot be modified so if you entered the wrong type you will need to discard the submission and start again (using the Cancel button at the bottom of the page).

Select the Histology required for the entire submission.

The Antibodies column is enabled only if IHC - PrP is selected under Histology. You must select at least one antibody from the Antibodies column if it is enabled. If the required antibody is not listed, please select the Other option and specify the antibody in the Submission Comments field below.

The Special Stain column is enabled only if Special Stain is selected under Histology. You must select at least one stain from the Special Stain column if it is enabled. If the required stain is not listed, please select the Other option and specify the stain in the Submission Comments field below.

Enter any specific comments in the Submission Comments text box. These comments will appear on the submission form when it is printed.

The Samples button takes you to the Sample Summary screen where you can add, edit and remove samples from the submission. You must add samples to the submission before it can be saved. Note that you have to select the Histology type before you can add samples.

Pressing Cancel will discard this submission and return you to the Home screen without saving any data.

The Finish button is only enabled once you have added samples to the submission. When you press the Finish button, you are saving the submission.

Pressing Finish will take you to the Print Submission screen if you are creating the submission, but not if you are editing it. (To print the submission form after editing it, use the print option on theView Submissions screen).Press Print Submission to view/print the submission form.Press Done when you are ready to return to the Home Screen.

The Delete Sample button is only active when a sample has been selected in the grid. Pressing Delete Sample will remove the selected sample from the submission.

This allows you to add samples with the same tissue list to the submission quickly. Pressing Copy Sample will take you to the Add Sample screen where you enter sender reference for the new sample.

Pressing Done will save all sample data and take you back to the Submission Details screen to complete the submission creation process.

Block Details

This screen lets you define the tissues for each of the blocks being submitted for the sample.

Enter the Block reference number in the Block Ref field. The default value is the next available Block Reference for the sample. If the submission is a pre cassetted, only Block references that have been pre booked can be entered. If a non-pre booked block reference is entered an error will be displayed. The the submission is not pre cassetted if the block reference entered is a block that has been pre booked an error will be displayed.

If you have your own reference number for the block, enter it in the Customer Reference field.

The Number of Blocks defaults to 1. You can override this if you want to submit several blocks containing the same tissues.

The Additional Request checkbox should be selected if this is a repeat request from a previously submitted block.

Step 1. Select the tissues in the block using the standard grid controls to add, edit and remove tissues. For each tissue type enter the number of pieces of that tissue in the block.

Step 2. Select the tests required for this block. The only available tests are those which were entered on the Submission Details screen. Note that if EO is selected, no other options can be selected for this block.

Check the Use these tests for the next block? checkbox if you would like the tests that you have specified above to be applied to the next block for this sample. This option is speeds up the process of creating blocks that require the same Histology.

Enter comments and details of other tests if necessary in the Comments field.

Clicking the Next Block button saves the entered data and clears the screen so that the details of the next block can be entered. If 'Use these tests for the next block?' has been checked, the same tests as those entered for the previous block will then be pre-selected.

Clicking the Cancel button will discard the data on this screen and return you to the Sample Blocks screen.

The Done button will save the data on the screen and take you back to the Sample Blocks screen to continue the submission.

Submission Status – Explanation

The following status’s are assigned to submissions depending on what stage they are at:

Not Received - The Customer has entered the submission onto the system, but as yet the submission has not been received by Histopath.

Received - Histopath have received the submission, and have recorded a Received Date and Time against that submission.

In Progress - For Wet Tissue Submissions, this means that Histopath have carried out some or all of the assigning tissues to blocks. For other submission types, it means some data has been entered on the Quality Data page.

On Hold - Histopath have placed the submission on hold due to a discrepancy. No quality data can be entered against the submission until it is taken off hold.

Rejected - This status can only be set on receipt of the submission, where Histopath decide to reject the submission due to a discrepancy or issue. A rejected submission will revert to being Not Received when the customer edits the submission via View Submissions (whether they make any changes or not). When the submission has been edited, and you are returned to the View Submissions screen, press Search to update the submissions grid.

Completed - All the tests on the submission have been dispatched.

Receive Submission

This screen allows you to set the selected submission to received. A summary of the submission is displayed at the top of the screen.

Change the Submission status from Not Received to Received if the samples and submission form are correct. If there is a problem with the submission which means the customer needs to resubmit the entire submission, change the status to Rejected.

If the submission status has been set to Received, you must enter the Date received, which defaults to today, the name of the person the submission has been Received by, which defaults to the name of the person entering the data, and the Time Received.

Enter the Post Fixations from the options provided. If Other is selected, enter the details in the comment box underneath.

If the customer checked the Additional Request checkbox for any sample on the submission when they entered the submission onto the system, the checkbox entitled This submission contains repeat blocks? will be checked.

The Reason field allows you to record the reason for changing the status, or any other comment. If the status is set to Rejected, you must enter a reason in to this field. When the customer edits the submission, the submission will automatically revert to being Not Recevied.

The Edit Submission button allows you to view the entire submission, and if necessary to edit it. It is expected that you would only make minor edits to the submission from here. If there are significant errors in the submission, the entire submission should be rejected and resubmitted by the customer (once they have made the necessary changes/corrections). Pressing Edit Submission will take you to the Submission Details screen where you can alter the submissions details.

Pressing Cancel discards the data entered and returns you to the Submissions Awaiting Receipt screen.

Pressing Done will save the data entered and complete the process of receiving the submission and will take you to the Print Submission page. Press Done to take you back to the Submissions Awaiting Receipt screen where you will see the submission is no longer in the list of submissions awaiting receipt (if you flagged the submission as being “Received” ).

Quality Data

This screen allows you to enter Quality Data for the selected submission. A summary of the submission appears at the top of the screen, underneath which is a grid displaying a summary of the quality data for each block.

By default the grid displays all the tests in the submission. To filter the list of tests displayed in the grid, select the Filter button and select a Histology Ref or Test (or both) on which to filter the grid results, then press Go. The grid will now only show tests with these attributes. To see the complete list of blocks for this submission again, select the All button to the left of Filter.

Each row in the grid is coloured to reflect the test status:

Green background indicates that the test is awaiting entry of the test result (see below).

Grey indicates a test result of Passed.

Purple indicates a Failed test. Tests have a white background when they have been dispatched.

To enter quality data, first select the test for which you wish to enter the data, by clicking the select column on that row (far right). If you wish to enter (the same) data for multiple tests at the same time, check the Select box for each test to be included (i.e. each row to be updated). The All checkbox above the grid allows you to select every row in the grid. Note, this will select all the rows on the grid across all the pages (if there is more than one page to the grid). Unchecking All will deselect all rows. When only one row has the Select column ticked, the details (if any) recorded against it will be displayed in the lower section of the screen. If you wish to update any details, simply change the fields, and then press Update Selected as described below.

Having selected the tests you want to enter the data for, enter the quality data in the fields beneath the grid.

The Test Result field can be set to Passed or Failed.

Enter the slide's Stain Ref if applicable.

If the test is being dispatched, tick the Dispatched checkbox. The Dispatched To field then defaults to the person who submitted the submission, the Dispatched Date defaults to today, and the Dispatched By field defaults to your name. These can be modified if needed.

Enter the Number of Blocks\Slides, which is set to a default of 1.

Enter a QC Code if applicable. If the Test Result is set to Failed, the QC code is mandatory.

QC Note checkbox -check this box if there is to be a QC note. The system will generate the QC note reference automatically. You will be given an opportunity to view, edit and print the QC notes generated on the submission you are operating on when you come to save your changes.

Select the Remedial Action if the Test Result is set to Failed.

If the slide is being archived, record the Archive Location, Archive Date, and an Archive Comment if required.

Select the appropriate Charges.

Finally a Comment can be applied to these tests.

To apply the entries you have made to the selected rows click the Update Selected button. This saves the entered data against all the tests that were selected on the grid. If none are selected, the button is disabled.

You can also use this page in view mode to see what quality, dispatch and archive data has been recorded against each test. To do this, simply tick on the arrow to the left of the row you wish to view – the lower part of the screen will display the data recorded against the selected sample. You can only view one row at a time – as soon as you tick the Select check box on more than one row, the lower section of the screen is blanked as each row ticked may have different data recorded against them.

The Cancel button will discard any data entered and return you to the Submissions Awaiting Quality Data screen.

Pressing Done will save the data entered and return you to the Submissions Awaiting Quality Data screen.

When you have pressed Done – if you applied any QC Notes to any of the tests you operated on, you will be taken automatically to the QC Notes screen. You can now edit the QC Notes and print as necessary. You can go back to the QC Notes as many times as you need, so you are not obliged to complete the details at this stage.

Archive Blocks

This screen lets you choose the specific blocks to archive and enter their archive details.

It can also be used to view archive details for any given block on the selected submission.

The grid will now only show blocks that match the filters you have specified. To see the complete list of blocks for this submission again, select All.

Use the Select column to select the rows to which you wish to apply archive details to. If you want to apply the details you are about to enter to all the rows, use the All tick box just above the Select column. Note, this will select all the rows on the grid across all the pages (if there is more than one page to the grid).

Archive Location - use this field to specify the archive location.

Archived Date - use this field to specify the archive date.

Comment - use this field to specify any comments.

Use the Update Selected button to apply the Archive Location, Archive Date and Comment to the rows you selected (using the Select column described above). The blocks selected will be updated with the data you entered, and the grid will automatically be updated to show these details.

Pressing Done will save any altered data to the database and return you to the Archive Submissions screen.

Pressing Cancelwill halt the process and return you to the Archive Submissions screen without saving any data.

If you wish to view the archive details for any one single row, click on the arrow at the beginning of that row. Details will be shown in the lower section of the screen (location, date and comment).

QC Notes

Use this option to edit previously created QC Note. You will also arrive on this screen when you have just finished entering quality data on the Quality Data if you had assigned one or more QC Notes to the tests on that page.

Edit QC Notes

This screen is presented when you select a QC Note to edit from the QC Notes screen.

The upper part of the page shows the header section – this is read-only, i.e. you cannot edit it.

The lower part of the screen contain the main body of the QC Note. When the QC Note was first created, the system will have be pre-filled this section with a table showing the Sender Ref, Histo Ref, Block Ref and Test for each test that the QC Note relates to. You can add your text below this table, or intersperse it with the table contents. As this field is fully editable, you are free to remove the table headings if you feel they are unnecessary.

The lower part of the page shows the name of the person who created the QC Note (i.e. attached it to a test on the Quality Data screen.), and the date on which this was done. This section is read only.

When you have finished editing the QC Note, press Done.

 

View Old ICC_Sub data

Use this option to view data that has been imported from the old access database. The Table pick list shows the tables that have been imported from the database, selecting a table from the list will display the Sender Ref, Histology Ref, Block Ref, Project, Date Submitted Species, Tissue and Comments fields for that table.

The Filter field allows the user to filter the search results similar to that of google. For instance the search string "04/5142 01" (inc quotes) would return all records where any of the fields exactly matched "04/5142 01". If 04/5142 01 was the filter criteria the search would return records where any of the fields matched "04/5142" or any of the fields matched "O1". Press GO to process the filter or press Clear to clear the filter and display all records

If a table is not chosen but a filter expression is entered, the criteria will be searched for across all tables.

This screen allows you to search for submissions by setting a variety of search criteria. The returned list will contain all submissions that match the criteria you have specified (using AND predicate logic)

The criteria are:

Submission Number - If you know the submission number, key it into this field and press Search. If the submission number is known, there is no need to type in any further criteria, as only a single result is possible (submission numbers are unique to each submission).

Submitted Area

Status

Submitted By

Project or Contract code

Fixation

Contact Name

Histology Ref

Species

Sender Ref

Submitted Date Between

Received Date Between

Once you have selected/entered the search criteria, press Search. The submissions matching all the criteria you have specified will be listed in the grid.

Pressing Done will return you to the Home Screen

Use the Print Submission button to view/print the submission form. This button will only be activated if you have selected a submission using the arrow to the left of any given submission listed in the grid. A Submission Form will be generated in pdf format If you have Adobe Acrobat Reader installed,the form can be printed or saved directly from your browser.

Note, for Wet Tissue submissions, this option will print the Histopathology version of the submission (i.e. block/tissue rather than tissue) if any of the tissues have been assigned to blocks using the Assign Tissues To Blocks option. If you want to see the original submission form showing the “tissue only” version, use the Print Submission option on the View Submissions screen.

The Edit Submission button will only be activated if you have selected an editable submission using the arrow to the left of any given submission listed in the grid. You cannot edit submissions that have a Completed status. You will be taken to the Submission Details screen where you can perform any editing required. If you then press the Samples button you will be taken to the Sample Summary screen, again with full edit capabilities.

The View Submission button will only be activated if you have selected a submission using the arrow to the left of any given submission listed in the grid. You will be able to view the submission (Submission Details and Sample Summary), but will not be able to edit any aspect of it.

The View Quality Data button will only be activated if you have selected a submission using the arrow to the left of any given submission listed in the grid. You can use all the filter and sort capabilities of the Quality Data screen, but you will not be allowed edit any of that data.

The View Archive button will only be activated if you have selected a submission using the arrow to the left of any given submission listed in the grid. You will be taken to a screen where you can select whether you want to look at Block or Tissue archiving. If you select Archive Blocks,you will be taken to theArchive Blocks screen. If you select Archive Tissues, you will be taken to the Archive Tissues screen. You will be able to use the filter facilities on these screen, but will not be allowed to edit any of the archive data.

The View Receipt button will allow you to view the receipt details for the selected submission- you will be taken to the Receive Submission where you can view the details entered when the submission was originally received.

Book Blocks

This screen allows you to book block references for samples.

To book blocks for a single sample enter the Sender ref into the Sender Ref to field.

To book blocks for a range of Sender refs enter the starting reference in the Sender Ref from field and the ending reference into the Sender Ref to field. Only PG numbers and mouse numbers can be entered in ranges. Note that that the blocks entered will be booked for each Sender Ref in the range.

If a range of Blocks is required enter the starting Block ref required into the Block ref from field and the end Block ref into the Block ref to field, otherwise just enter the requested block into the Block Ref from field.

Finally press the Book button. The system will ask if you are sure you want to do this. If you are in any doubt about what you have entered, manoeuvre this dialog box so that you can see the details you entered. If you want to change what you entered, press the Cancel button and make the changes before pressing Book again, otherwise press OK to book the Blocks. The system will report if the Books have successfully booked. If any blocks could not be booked they will be reported at the bottom of the screen.

Use the Check Used Blocks Refs link to check what blocks have already been used for a Histology reference.

You can continue to book more blocks if required, or press Done to return to the Booking menu.

Audit Logs

This screen gives you access to the system's audit logs.

Use Daily Audit Log to see the audit log for a particular day. Select the date using the Log Entries On field, and then press Search. Alternatively, press Audit Log Menu to be returned to the audit log menu.

Use Audit Log By User to see the audit log for a particular user. Select the dates between which to you wish to view the audit for using the Log Entries Between date fields. Use User to select the user you wish to audit. Press Search to run the audit. Alternatively, press Audit Log Menu to be returned to the audit log menu.

Use Audit Log By Submission to see the audit log for a particular Submission. Select the dates between which to you wish to view the audit for using the Log Entries Between date fields. Use Submission Number to enter the submission you wish audit. Press Search to run the audit. Alternatively, press Audit Log Menu to be returned to the audit log menu.

Once you have pressed Search on any of the above three screens, you will be presented with a grid showing the audit trail. Unfortunately, for most fields, the audit trail does not show the actual values in the Before and After columns, but instead shows the system values.

Note: If you do not enter a date range between which the audit is to be performed, it may take some time for the system to return a result (Audit Log By Submission).

You can export the results from the grid to Excel (see Export to Excel).
