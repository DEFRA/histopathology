General Information

The page header

A common page header section is displayed at the top of each page in the system.

The centre section of the page header displays the name of the system ("Histopathology Submissions"), the version of the system, the name of the page you are currently viewing, and a "breadcrumb trail" showing you which section of the system you are in.

The right hand block of the page header displays the name of the currently logged-on user, the user group and area that the user is assigned to. It also displaysthe current submission number if you are editing or processing a submission. Below this are two links that allow you to return to the home screen or access the help pages from anywhere in the system.

 

Date entry controls

To enter a date in a date entry control, click the calendar button to the right of the text box:

A calendar will be displayed allowing the selection of a date. To close the calendar again without selecting a date, click the calendar button a second time.

Alternatively, a date may be directly typed in the box (in the format dd/mm/yyyy).

 

Data grids

To select a row in a data grid, click the arrow button at the left-hand end of the row: . The selected row will be highlighted in a different colour.

The buttons at the bottom of the grid may be used to perform row operations:

   Add a new row

   Edit the currently selected row

   Remove the currently selected row from the grid

After pressing the New or Edit button, the grid will be placed in to edit mode, and you can change the values in the cells. After making changes, use the following buttons to confirm or cancel those changes:

   Save changes

   Cancel changes - the data in the row will revert to the values that were present before entering edit mode.

If the New, Edit or Delete buttons appear in grey; this indicates that the particular function is unavailable at this time.

If a grid contains more than one page of data, then the navigation buttons at the bottom left of the grid may be used to change between pages:

   Move to the first page

   Move to the previous page

   Move to the next page

   Move to the final page

The page number links, next to the navigation buttons, can be used to move directly to a given numbered page. At the bottom right of the grid the currently displayed page number is shown, along with a count of the total number of pages available.

Some grids will allow sorting by means of clicking on the column headers. If this is the case, then the column headers will appear underlined. The first click on the column header will cause the grid rows to be sorted by that column in ascending order; a second click on the same column will sort in descending order.

 

Pick Lists

You will find that all pick lists have an empty entry as the first entry. This is so that it is readily distinguishable which field shave had data entered and which have not. It also allows you to blank out the field from a previous selection. For example, if you have filled in some search criteria on the View Submissions page and now wish to remove one, rather than having to clear the whole criteria using Clear Search, you can just change the particular field entry to the blank entry in the pick list, and press Search.

 

Field error messages

If required data is missing, or invalid data has been entered when a form is saved, the error may be indicated by a red star next to the relevant field. Placing the mouse cursor over the star will cause a tool tip message to pop up, indicating the reason for the error: for example, it may indicate that the field is mandatory, or in the case of an invalid entry, it may indicate the required format.

 

Export to Excel

Data displayed in several of the grids can be saved and viewed as an Excel spreadsheet. When you click on this link, an empty ExcelExport browser window will open and a File Download box displayed, asking if you want to Open or Save the file. Selecting Open will load the file into Excel from where it can be saved to your local disk. Selecting Save will display the Save As dialog box prompting you to enter the file name. You may need to close the Download box when the file has been saved. You can then close the ExcelExport browser window as it is no longer required.

 

Saving Data

Data is only saved to the system when you press the Finish or Done button on the screen. Until then, the data is being stored and manipulated on the screen only.

  

Application Error

This screen is displayed if the system has encountered an unexpected problem. Details of the error are shown, which a system administrator may be able to use to determine the cause of the problem.

The information displayed will also have been recorded in the system log, which the system administrator can view. To help the administrator determine the cause of the problem, you can record additional information about what you were doing when the error occurred in the text box at the bottom of the screen. Click the Save button and the information you entered will also be saved to the system log, for later analysis by the system administrator.

After an error has occurred, it is advisable to use the Home link in the page header to return to the Home screen. If the error has occurred before the data you were working on was saved, that data will have been lost.

The Home screen displays a number of links, through which all other parts of the system are accessed.

Submission Type

This screen asks whether the submitted tissue is in the form of cassettes, sections, wax blocks or wet tissue. One of these options must be selected before you can create a new submission. Only one may be selected per submission.

Clicking the Cancel button will halt the process and return you to the Home screen without saving any data.

Clicking the Next button will direct you to the Submission Details screen to begin the process of creating a new submission for the selected type of submission.

 

Submission Details

This screen asks for general information concerning the submission.

The Entered By field will be pre-filled and cannot be edited. It shows which user entered the submission onto the system. Entered Area shows which Area this user belongs to.

The Submitted By field is set to the logged on user's name by default. Select the name of the submitter from the drop-down list if you are entering the submission on someone's behalf. If the name of the submitter does not appear in the drop-down list, click on the New button, which will allow you to add their name to the list, from the standard grid controls. The Submitted Area field will be set to the area to which you belong. You will not normally be able to change this field.

Select the Project or Contract code for which you are submitting the samples from the drop-down list. Only one project code may be selected per submission. If the code does not appear on the list, use the New button to add a new project code from the standard grid controls. The Submission Date defaults with today's date. If you wish to enter the submission on the system in advance of submitting the material, you can change the date using the Date Entry control.

Select the Pathologist from the drop-down list. If the pathologist does not appear on the list, use the New button to add a new pathologist from the standard grid controls. This field is mandatory.

Select the required fixation from the drop-down list.

Select the Species of the samples being submitted from the drop-down list. Only one species may be selected per submission. If the species required is not on the list, you will need to contact Histopathology. This field is mandatory.

In the Is it adequately fixed? field, select Yes or No as appropriate. This field is mandatory.

Some users will have an additional Same project code for all samples? checkbox displayed, where the system is integrating with another database. By default this option is checked, which means you will not be able to add samples to the submission that have different project code. Turning off this option will allow you to mix samples from different project codes on the same submission.

Submitted As displays the option you selected on the previous Submission Type page. This cannot be modified so if you entered the wrong type you will need to discard the submission and start again (using the Cancel button at the bottom of the page).

Select the Histology required for the entire submission.

The Antibodies column is enabled only if IHC - PrP is selected under Histology. You must select at least one antibody from the Antibodies column if it is enabled. If the required antibody is not listed, please select the Other option and specify the antibody in the Submission Comments field below.

The Special Stain column is enabled only if Special Stain is selected under Histology. You must select at least one stain from the Special Stain column if it is enabled. If the required stain is not listed, please select the Other option and specify the stain in the Submission Comments field below.

Enter any specific comments in the Submission Comments text box. These comments will appear on the submission form when it is printed.

The Samples button takes you to the Sample Summary screen where you can add, edit and remove samples from the submission. You must add samples to the submission before it can be saved. Note that you have to select the Histology type before you can add samples.

Pressing Cancel will discard this submission and return you to the Home screen without saving any data.

The Finish button is only enabled once you have added samples to the submission. When you press the Finish button, you are saving the submission.

Pressing Finish will take you to the Print Submission screen if you are creating the submission, but not if you are editing it. (To print the submission form after editing it, use the print option on theView Submissions screen).Press Print Submission to view/print the submission form.Press Done when you are ready to return to the Home Screen.

Sample Summary

This screen shows a summary of the samples associated with this submission. The first time you go into the page, the grid of samples will be empty as the submission will contain no samples. This screen operates in two modes –  Wet Tissue submissions (where the Sample Summary show tissues against samples), and Block type submissions (where the Sample Summary shows just the Samples).

The Click here to expand all tissues and Click here to collapse all tissues links will expand and collapse the grid to show or hide all tissues for each sample.

To add a sample to the submission, click on the Add Sample button. This takes you to the Add Sample screen to start the process of assigning a sample to the submission.

The Edit Sample button is only active when a sample has been selected in the grid. Pressing Edit Sample takes you to the Sample Details screen where you can edit the sample's details.

The Delete Sample button is only active when a sample has been selected in the grid. Pressing Delete Sample will remove the selected sample from the submission.

The Copy Sample button is only active when a sample has been selected in the grid. This option copies the tissue list entered for the selected sample to another sample. This allows you to add samples with the same tissue list to the submission quickly. Pressing Copy Sample will take you to the Add Sample screen where you enter sender reference for the new sample.

Pressing Done will save all sample data and take you back to the Submission Details screen to complete the submission creation process.

Add Sample

This screen starts the process of adding a new sample to the submission.

Enter the Sender Reference for the sample you are adding to the submission and press Next.

There is a lookup facility built into this page. If you want to see iff you have submitted a particular Sender Reference perviously, enter part of it into the field and click on the Click here link. The system will search for that text/number and return all Sender Refs that contain it. For example, if you entered Red the returned list could include such entries as "Red-1342", "12/02-Red" or "12Red-15". The results will be displayed in a grid - if the Sender Reference you require is listed, click on it to select it - the system will port the reference into the field and you can press Next to continue with that reference. Alternatively, if the Sender Reference you require is not list, press Back to try again.

Pressing Back will return you to the previous screen without saving any altered data.

Pressing Next will take you to the next screen to enter which tissues you are submitting for this sample. The format of this page depends on the submission type and is entitled Sample Details for wet tissue submissions, and Sample Blocks for all other types of submissions.

For some users, the Project Code and Species for the given sample are imported from other databases when the Next button is selected. Select the required Project code and Species before clicking on Next again. In these cases, the project code and species of each sample must correspond to the overall selection for the submission, and an error is displayed if they do not match.

If you did not select a Project Code or Species on the Submission Details page, then the project code and species selected for the first sample entered against the submission will become the Project Code and Species for the whole submission.

The Delete Block button is only active when a block has been selected in the grid. Clicking Delete Block will remove the block from the submission.

The Copy Block button is disabled for most users. It allows blocks to be created quickly when assigning tissues to blocks on receipt of wet tissue submissions.

Clicking Done will save the Block data and take you back to the Sample Summary screen and displays all Samples entered on the submission.

Block Details

This screen lets you define the tissues for each of the blocks being submitted for the sample.

Enter the Block reference number in the Block Ref field. The default value is the next available Block Reference for the sample.

If you have your own reference number for the block, enter it in the Customer Reference field.

The Number of Blocks defaults to 1. You can override this if you want to submit several blocks containing the same tissues.

The Additional Request checkbox should be selected if this is a repeat request from a previously submitted block.

Step 1. Select the tissues in the block using the standard grid controls to add, edit and remove tissues. For each tissue type enter the number of pieces of that tissue in the block.

Step 2. Select the tests required for this block. The only available tests are those which were entered on the Submission Details screen. Note that if EO is selected, no other options can be selected for this block.

Check the Use these tests for the next block? checkbox if you would like the tests that you have specified above to be applied to the next block for this sample. This option is speeds up the process of creating blocks that require the same Histology.

Enter comments and details of other tests if necessary in the Comments field.

Clicking the Next Block button saves the entered data and clears the screen so that the details of the next block can be entered. If 'Use these tests for the next block?' has been checked, the same tests as those entered for the previous block will then be pre-selected.

Clicking the Cancel button will discard the data on this screen and return you to the Sample Blocks screen.

The Done button will save the data on the screen and take you back to the Sample Blocks screen to continue the submission.

Print Submission

This screen allows you to print a report of the recently created submission.

Pressing Print Submission will generate a report for the submission in pdf format. You will need to have Adobe Acrobat Reader installed on your pc. The report will be displayed in a separate browser window from where it can be printed or saved. You should print out the form and send it with your samples to Histopathology.

When you have printed the submission form, you can close the window that displays the form, and press Done to return to the Home screen. The submission form can also be printed at a later date from the View Submissions page.

Note: Each time you select Print Submission, a new window is opened. So, if you do not close down the window after viewing/printing a submission and then select Print Submission again later, there will be more than one Submission Form window open. It is advisable to close Submission Form windows down after you have finished with them to avoid confusion later.

 

View Submissions

This screen allows you to search for submissions that have been submitted from your customer area. By default all the submissions from your area are displayed in the grid at the bottom of the page. Enter search criteria to filter the list of displayed submissions if you wish to narrow the list of submissions displayed, or search for particular submissions. You can filter by any combination of the following fields.

The Submission number is a number assigned by the system to each submission, and is displayed on the printed submission form.

Entered by is the name of the person who entered the submission on the system.

Each submission is assigned a Status that is updated as it is processed. A status of "Not Received" means it has been created but the samples have not yet been received by Histopathology. Once a submission has finished being processed, it's status changes to "Completed".

Submissions that have been rejected can be modified and re-submitted (see Edit Submission below).

The remaining fields reflect the data entered on the Submission Details screen, except for the Submitted Date and Received Date fields. For these, enter the date range you wish to search between using the date control if preferred. If you enter just one of the "from/to" dates in which case you will get all submissions since or before the given date.

The Search button displays the list of submissions that match your critieria in the grid below.

Clear Search clears all search criteria and lists all submissions from your area.

You can export the search results from the grid to Excel (see Export to Excel).

Below the grid you will see a number of buttons that allow you to carry out various operations on individual submissions. These buttons are enabled only when a submission is selected. Click to the left of a row on the grid to select it.

The Print Submission button will generate a submission form in pdf format. If you have Adobe Acrobat Reader installed, the report can be printed or saved directly from your browser.

Copy Submission takes you to the Copy Submission screen where you can copy samples, blocks, or tissues from the current submission to another submission.

The Edit Submission button is only enabled if the submission hasn't already been received by Histopathology, or the submission has been rejected. This option will take you to the Submission Details screen where you can edit any details about that submission.

The View Submission button also takes you to the Submission Details screen where you can view, but not edit, the details of the submission.

The Receive Submission button is disabled for most users, it allows Histopathology to record the receipt of a submission.

Copy Submission

This page allows you to create new submissions using an existing submission as a template. The tissues or blocks that have been submitted for each sample are copied to the new submission for different samples.

The grid displayed on the page lists all the samples in the selected submission, in the column labelled Sender Ref. To copy these to the new submission, select each Sender Ref row in turn by clicking to the left of the row. Then press the Change button to go to the Add Sample screen where you enter the sender reference that is to go on the new submission. The Copy Submission page will now be updated to show the new sender ref in the second column of the grid.

Any samples that do not have a New Sender Ref entered against them in the grid will not be included on the new submission.

Cancel will halt the process of copying the submission and return you to the View Submissions screen without saving any data.

When you click Finish, a popup message will ask you whether you are sure that you want to create a new submission based on the previous one. If you press Yes, you will be taken to the Submission Details screen to complete the rest of the submission details.

Submission Status – Explanation

The following status’s are assigned to submissions depending on what stage they are at:

Not Received - The Customer has entered the submission onto the system, but as yet the submission has not been received by Histopath.

Received - Histopath have received the submission, and have recorded a Received Date and Time against that submission.

In Progress - For Wet Tissue Submissions, this means that Histopath have carried out some or all of the assigning tissues to blocks. For other submission types, it means some data has been entered on the Quality Data page.

On Hold - Histopath have placed the submission on hold due to a discrepancy. No quality data can be entered against the submission until it is taken off hold.

Rejected - This status can only be set on receipt of the submission, where Histopath decide to reject the submission due to a discrepancy or issue. A rejected submission will revert to being Not Received when the customer edits the submission via View Submissions (whether they make any changes or not). When the submission has been edited, and you are returned to the View Submissions screen, press Search to update the submissions grid.

Completed - All the tests on the submission have been dispatched.
